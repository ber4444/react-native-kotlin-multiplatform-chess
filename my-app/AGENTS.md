# Expo SDK 56 & Continuous Native Generation (CNG) Guidelines

- Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.
- **Do NOT manually edit or commit `android/` or `ios/` folders**. They are ephemeral and generated by `npx expo prebuild`.
- **Native Configuration**: All permissions, plugins, and build properties belong in `app.json` or config plugins under `plugins/` (e.g., `plugins/withGradleHeap.js`).
- **Native Code**: Custom native code belongs in local Expo modules under `modules/` using the Expo Modules API (e.g., `modules/stockfish`).
- **Clean Regeneration**: When changing native config or plugins, run `npx expo prebuild --clean`.
- **Development Builds**: Run `npm run android` / `npm run ios` for development builds (using `expo-dev-client`).
